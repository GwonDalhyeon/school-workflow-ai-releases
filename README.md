# 학교 업무 AI — 배포

쿨메신저·아이좋아 메신저 메시지를 AI가 읽고 할 일·일정으로 정리해 주는 개인용 도구의 배포 파일을 올려 두는 곳입니다.

- 처음 설치: [Releases](../../releases/latest)에서 `SchoolWorkflowAI-<버전>.zip`을 받아 풀고 `학교 업무 AI 설치.bat`을 실행합니다.
- 업데이트: 설치한 앱이 새 버전을 알려 주면 앱 안에서 ‘업데이트’를 누릅니다.
- `stable.json`·`beta.json`: 앱이 새 버전을 확인하는 버전 정보(개발자 서명 포함). 직접 받을 필요는 없습니다.

교육청·학교의 공식 프로그램이 아니며, AI 이용 요금은 각자 부담합니다. 사용 안내는 설치 파일 안의 `사용 안내.txt`에 있습니다.
